# 💖 To-Do List for My Boyfriend

A cute web-based To-Do List application. This project is designed to help keep track of "tasks" with a clean, responsive UI and persistent storage.

## ✨ Features
- **Add Tasks:** Quickly add new items to your list.
- **Interactive UI:** Click a task to mark it as completed (strikethrough effect).
- **Delete Tasks:** Remove tasks easily using the "✖" button.
- **Data Persistence:** Uses `localStorage` so your list remains even if you refresh or close the browser.
- **Responsive Design:** Beautifully styled with a pink gradient theme that works on both desktop and mobile.

## 🛠️ Built With
- **HTML5:** For the application structure.
- **CSS3:** Custom styling featuring Google Fonts (Poppins) and smooth transitions.
- **JavaScript (ES6):** Logic for adding, deleting, and saving tasks to the browser memory.
